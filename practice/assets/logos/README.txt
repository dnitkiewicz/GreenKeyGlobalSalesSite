Partner logo files go here.

Expected filenames, referenced by the credibility bar on every page:

  ahla.svg            American Hotel & Lodging Association
  hotels-canada.svg   Hotels Canada
  travalyst.svg       Travalyst
  booking.svg         Booking.com

SVG is preferred. PNG with a transparent background also works, but you
must then change the file extension in the HTML to match.

The bar sits on a dark green background and the CSS applies a white filter
(brightness(0) invert(1)), so supply single-colour or solid-dark artwork.
A full-colour logo will be flattened to white.

Until a file is present the browser shows the alt text instead, so the bar
still reads correctly. Nothing breaks while you wait for the assets.

BEFORE USING ANY OF THESE: confirm usage rights and the required lockup
with Marketing. See notes in the project README.
