# Green Key Global sales site

Practice build. Every page is `noindex, nofollow`. Not approved for publication.

The visible draft label has been removed at Dave's request. The `noindex, nofollow`
meta tag on every page is the actual protection and remains in place, so search
engines will not list the site. Note that this does not make the pages private: if
the folder is pushed and deployed, anyone with the URL can open it.

## Running it

The question library reads `data/questions.json` over `fetch`, which browsers block
for `file://` URLs. Opening `index.html` by double-clicking will work for every page
except `questions.html`, which will show a message explaining this.

Serve it locally instead:

```bash
cd site
python3 -m http.server 8000
# then open http://localhost:8000
```

On GitHub Pages it works with no extra setup.

## Regenerating the question data

`data/questions.json` is generated from `GKV4_QA_Master_English_20260424.xlsx`.

```bash
python3 build_questions.py
```

It produces 213 questions and 37 Core Criteria, which matches the known figures and
is the check that the extraction is faithful.

The assessment version is tracked in the JSON metadata for your reference but is
deliberately not shown anywhere on the site. Internal version numbers mean nothing
to a prospect and date the page unnecessarily. Pages say "the current Eco-Rating
assessment" and point to greenkeyglobal.com as the source of record.

**The extractor deliberately drops every scoring column.** No point values, no
answer-option weights, no section totals. It keeps question text, section,
documentation requirement, answer options, and whether an option is mandatory.
If the workbook is updated, rerun this rather than editing the JSON by hand.

## Regenerating pages

`build_pages.py` writes the five pages that share the nav and footer, so those stay
in sync. `index.html`, `questions.html` and `readiness.html` are hand-maintained
because each has page-specific markup.

If you change the nav, change it in `_partials.py`, rerun `build_pages.py`, and then
update the three hand-maintained pages to match.

## Rules this build follows

Carried from `CLAUDE.md` and the site brief.

- No Eco-Rating point values and no Key rating score bands, anywhere
- No em dashes or en dashes
- All CTAs route to `Sales@greenkeyglobal.com`, never an individual
- Every statistic shows its source and year on the page
- Every number renders as text in the markup, never generated by script
- The readiness checklist stores nothing and says so before the first question
- No email gate on anything
- ECGT (Directive (EU) 2024/825) is not conflated with the proposed Green Claims
  Directive, COM 2023/166, which is not law

## Partner logos

The credibility bar expects four files in `assets/logos/`:

```
ahla.svg            American Hotel & Lodging Association
hotels-canada.svg   Hotels Canada
travalyst.svg       Travalyst
booking.svg         Booking.com
```

Until a file exists the slot falls back to the organisation's name as text, so the
bar reads correctly either way and nothing breaks while artwork is pending.

The bar sits on dark green and the CSS applies a white filter, so supply
single-colour or solid-dark artwork. Full-colour logos will flatten to white.

**Confirm usage rights before adding any of these.** AHLA and Hotels Canada are the
programme's joint owners, so internal approval is likely straightforward. Travalyst
and Booking.com are recognition relationships rather than ownership, and both
maintain brand guidelines that govern how their marks may be displayed, including
required clear space and prohibitions on implying endorsement of a specific claim.
Marketing owns this decision.

## Known gaps

- **Pricing page is not built.** No confirmed pricing to publish, and the Terms and
  Conditions discount language is unresolved.
- **No testimonials or case studies.** Those assets belong to Marketing and usage
  rights have not been confirmed.
- **The auditing firm is not named**, pending a decision on whether naming it
  conflicts with the evergreen rule. The impartiality claim still works without it.
- **Per-role hour estimates are illustrative.** Only the four to six hour total is
  measured. This is stated on the page rather than implied.
- **No scale figure is published.** Membership counts and certification counts differ
  and have not been reconciled, so the site claims neither.
- **Publishing question text externally is not approved.** `questions.html` is built
  so the approach can be reviewed, not so it can ship.

## Accessibility and performance notes

- Fonts are self-hosted rather than loaded from a CDN, because hotel corporate
  networks frequently block font CDNs. Total font payload is about 290 KB.
- No third-party scripts, no analytics, no cookies, no storage of any kind.
- The site works with JavaScript disabled except for the question filters and the
  checklist result, both of which are enhancements rather than content.
- Tables collapse to labelled cards below 700px rather than scrolling horizontally.
- `prefers-reduced-motion` is respected.
